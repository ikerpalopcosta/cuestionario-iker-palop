# Cuestionario de redes

Cuestionario interactivo sobre redes informáticas, cableado UTP, estándares T568A/T568B, herramientas y fibra óptica. Incluye 30 preguntas, presenta 10 al azar en cada tanda y corrige automáticamente sobre 10 puntos.

**Autor:** Iker Palop

## Publicación

GitHub Actions publica automáticamente el contenido de `index.html/` en GitHub Pages al actualizar la rama `main`.
